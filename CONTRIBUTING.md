# Contributing

Thank you for helping build a practical, accessible engineering laboratory.

1. Open an issue explaining one precise failure mode and its consequence.
2. Use synthetic data and a reproducible scenario.
3. Show a correct implementation, a deliberately broken one and an assertion that distinguishes them.
4. State what remains untested. Do not describe simulation results as certification.
5. Keep beginner documentation in plain British English.

**Safety:** No credentials, private data, remote exploitation targets or unapproved external effects. Contributors retain attribution; maintainers review before merging.
